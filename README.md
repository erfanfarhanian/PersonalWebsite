# Personal Portfolio Website

[![Framework](https://img.shields.io/badge/.NET-5.0-512BD4?style=flat-square&logo=dotnet&logoColor=white)](https://dotnet.microsoft.com/)
[![Database](https://img.shields.io/badge/MSSQL-Server-CC292B?style=flat-square&logo=microsoftsqlserver&logoColor=white)](https://www.microsoft.com/sql-server)

The full source code of my personal website and portfolio, featuring a responsive portfolio and a secure administrative dashboard for real-time content management.

---

## ✨ Key Features

### 👤 Public Showcase
- **Interactive Resume:** Dynamic rendering of career history, academic background, and technical proficiencies.
- **Project Catalog:** Structured showcase of production applications and technical experiments.
- **Fully Responsive:** Mobile-first layout implemented with Bootstrap and custom CSS.

### ⚙️ Content Management Dashboard
- **Role-Based Authentication:** Secure administrator login and session management.
- **Dynamic CRUD Engine:** Full management capabilities for site entries, skills, and portfolio records.
- **Data Mapping:** Efficient database persistence powered by Entity Framework Core.

---

## 🛠️ Tech Stack

- **Backend:** C#, ASP.NET Core, Entity Framework Core
- **Database:** Microsoft SQL Server
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
- **IDE:** Visual Studio 2022
